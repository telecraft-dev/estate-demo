# estate-demo

The curated demo estate behind **https://demo.telecraft.dev** — a read-only Telecraft console fed from this repository (see telecraft-dev/telecraft#50).

Everything here is synthetic: teams, Services, Tiers, Blueprints, requirements and allow-lists chosen to show the interesting governance states (violations, waivers, drift, ungoverned collectors, a rollout in progress). Push to this repo and the demo rebuilds — the demo pipeline is the product pipeline.

For the CI contract-test fixture, see the private estate-fixture repo instead.
